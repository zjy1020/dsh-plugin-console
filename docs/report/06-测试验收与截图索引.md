# 06 · 测试验收与截图索引

> 本章是「DSH 插件台」的验收账本，写法是**证据优先**：每条结论都要能指回一个文件、一条命令输出或一张截图；指不回去的一律写「未核实」，不填数字。
> 证据三类：① `docs/shots/` 截图与过程日志（本章尺寸由 Pillow 逐张读出）② `scripts/` 探针脚本本体 + 头部注释（用途全部取自注释原文，不靠文件名猜）③ `docs/_*.json` 探针落盘输出，以及父会话运行日志里的 tool/result 原文（用于补脚本没落盘的几处数字）。
> 本章只做记录与索引，不产生新的实测。

### 1.3 尺寸口径说明（读图时必须知道）

目录里存在**三种像素口径**，这不是脏数据，而是三条不同的截图通道：

- **1980×1323（22 张）** —— CDP `Page.captureScreenshot`。评审静帧一律走这条，不含窗口边框。
- **1983×1324（16 张）** —— Win32 `PrintWindow`。比 CDP 大 3×1 px，正好是窗口边框；`screenshot.ps1` 的通道。
- **2561×1529（3 张）** —— `gallery*.png` 所在通道。与 1980×1323 同代但宽高各多 ~581/206 px，**具体通道未核实**。
- **2560×1600（6 张）** —— 整屏抓取（任务栏实拍、A/B 实验），与显示器分辨率一致。
- **1334×889（2 张）** —— **早期未做 DPI 感知的错误尺寸**，150% 缩放下的逻辑坐标。
- **32×32 及其余（20 张）** —— 图标级裁切 / 中间产物裁切（264/288/396/432/570/724/792/1012/1150/1280/1024）。
